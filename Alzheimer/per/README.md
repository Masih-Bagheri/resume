# طبقه‌بندی تصاویر MRI آلزایمر — فارسی

[معرفی پروژه](../README.md) · [English](../eng/README.md) · [Deutsch](../ger/README.md)

این پروژهٔ دانشگاهی با KNN تصاویر را در چهار کلاس دیتاست طبقه‌بندی می‌کند. تصاویر خاکستری و ۶۴×۶۴ می‌شوند؛ سپس استانداردسازی، PCA و انتخاب تنظیمات KNN با اعتبارسنجی متقابل انجام می‌شود.

## نصب و آموزش

ترمینال را داخل پوشهٔ Alzheimer باز کن، نه داخل per:

```bash
python -m pip install -r requirements.txt
python src/train.py
```

دیتاست را طبق [راهنمای دیتاست](../data/DATASETS.md) دانلود و مرتب کن. وقتی مسیر خواسته شد، پوشه‌ای را بده که Train و Val مستقیماً داخل آن هستند؛ هر دو باید چهار زیرپوشهٔ کلاس داشته باشند.

مدل در models/knn_model.joblib ذخیره می‌شود. گزارش ارزیابی و ماتریس درهم‌ریختگی در results قرار می‌گیرند. خروجی ترمینال آموزش انگلیسی است.

## اجرای برنامه

```bash
python src/app.py
```

از انتخاب‌گر بالای برنامه «فارسی» را انتخاب کن و دکمهٔ انتخاب تصویر MRI را بزن. نتیجه همراه شناسهٔ اصلی کلاس نمایش داده می‌شود. با تغییر زبان، نتیجهٔ فعلی هم ترجمه می‌شود؛ آموزش مجدد لازم نیست. تصویر اختیاری پس‌زمینه باید assets/Brain.png باشد.

اگر مدل موجود نباشد، هنگام زدن دکمه پیام راهنما نمایش داده می‌شود و پنجره باز می‌ماند. تصاویر ناخوانا پیام خطا می‌دهند. جزئیات خطای کتابخانه‌ها ممکن است انگلیسی باشند.

## نتیجهٔ نمونه

۴۳۰ تصویر آموزش و ۳۶۴ تصویر ارزیابی؛ دقت ۵۴٫۱۲٪ و خطا ۴۵٫۸۸٪. این نتیجه مربوط به دیتاست نمونهٔ توسعه است، نه کل دیتاست. [گزارش ارزیابی](../results/evaluation.txt).

## محدودیت‌ها

پروژه آموزشی است و اعتبارسنجی بالینی نشده. برنامه MRI بودن ورودی را بررسی نمی‌کند. جداسازی بیماران در نمونه تأیید نشده؛ تصاویر یک بیمار و نسخه‌های افزایش‌داده‌شدهٔ یک تصویر نباید بین آموزش و ارزیابی پخش شوند. این دقت، اعتبار پزشکی برنامه را نشان نمی‌دهد.
